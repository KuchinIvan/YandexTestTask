# Yandex Disk API Tests

## Стек
- Java 17
- JUnit 5
- REST Assured

## Что тестируется

- **информация о диске:** получение общей информации
- **работа с папками:** создание пустых папок, проверка конфликтов при повторном создании
- **управление файлами:**
    - загрузка валидного файла
    - ароверка конфликтов при повторной загрузке существующего файла
    - получение метаинформации о файлах и папках
- **копирование и перемещение:**
    - копирование и перемещение ресурсов между директориями
    - обработка ошибок при работе с несуществующими источниками 
- **удаление:** зачистка существующих ресурсов и попытки удаления несуществующих объектов.

## Требования
- JDK 17+
- Maven
- OAuth token

## Настройка

создать файл .env в корневом директории и добавить OAuth-токен:
```env
YANDEX_DISK_OAUTH_TOKEN= `CHANGE_ME`
```
## Запуск

mvn test
